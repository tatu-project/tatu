# Vision and Principles

Tatu is a free-first, open-source personal AI agent intended to work continuously, remember useful context, research current information, execute scheduled work, and act only within explicit permissions.

Working anchors:

- Free is an architectural constraint, not a reduced tier.
- The default path remains zero-cost whenever technically possible.
- The beginner experience stays simple while advanced controls remain inspectable.
- Providers and infrastructure remain replaceable and self-hosting remains viable.
- Deterministic application code enforces permissions and confirmation boundaries.
- The first useful vertical slice is a daily, cited AI-news briefing.
