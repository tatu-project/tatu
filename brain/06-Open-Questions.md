# Open Questions

- What does the first actual owner Colab pairing/Tatu answer prove, and which
  stop/revoke/active failure cases still require real evidence?
- Which managed scheduling bridge can invoke the independent dispatcher, with
  what verified entitlement/cadence and actual due-occurrence proof?
- How will the independent deployment and identity migration be verified without
  copying platform IDs or assuming private account access/free billing?
- What explicit retention/deletion mechanism should handle expired records when
  configuration is disabled, without claiming automatic timed erasure today?
- What client-key vault recovery/delegation UX and native/account/audio adapters
  should be accepted after the first online flows work?

Product choices already settled: online mobile-first path, no mandatory local
models, NotebookLM audio goal, optional personal Colab, OpenRouter cancellation
and public/private configuration separation. No private installation details
belong here. [ROADMAP.md](../ROADMAP.md) owns blockers/next action; [PRD.md](../docs/PRD.md)
connects the requirements, and [[03-Decisions-Index]] links accepted choices.
