# Tatu Project Brain

This directory is a small, Git-versioned, Obsidian-compatible navigation and continuity layer for Tatu.

Start at [[00-Home]] and read [[04-Current-State]] at the beginning of each Codex session.

## Authority boundaries

- [`PROJECT.md`](../PROJECT.md) is authoritative for product vision, architecture, principles, and scope.
- [`ROADMAP.md`](../ROADMAP.md) is authoritative for stages, checks, progress, blockers, and next actions.
- [`docs/decisions/`](../docs/decisions/) contains the authoritative record for individual technical decisions.
- Code and automated tests are authoritative for implemented behavior.
- This brain links and summarizes those sources. If a note conflicts with an authoritative source, the authoritative source wins and the note must be corrected.

Store only durable project context. Never store credentials, secrets, private user or customer data, raw logs with sensitive payloads, personal Codex configuration, or full chat transcripts.
